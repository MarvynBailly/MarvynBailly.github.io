About This Simulation

This is a real-time implementation of the Navier-Stokes equations for incompressible fluid dynamics, running entirely on your GPU using WebGL.

How to Interact

  • Mouse/Touch Drag: Add velocity and color to the fluid
  • Multiple Fingers: Create multiple disturbances simultaneously

Techniques Used

  • Semi-Lagrangian advection for unconditional stability
  • Pressure projection via Jacobi iteration
  • Vorticity confinement to preserve detailed motion
  • Bloom and sunrays for visual enhancement
