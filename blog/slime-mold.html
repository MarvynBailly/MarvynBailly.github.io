Slime Mold Simulation

Emergent Behavior from Simple Rules

This project simulates the behavior of slime mold (Physarum polycephalum) using simple agent-based rules. Thousands of particles follow pheromone trails, creating beautiful organic patterns that emerge naturally from local interactions.

Inspiration

Physarum polycephalum is a single-celled organism that exhibits remarkable problem-solving abilities. Despite having no brain, it can find the shortest path between food sources and has even been used to model efficient transportation networks.

This simulation recreates its behavior computationally, demonstrating how complex patterns can emerge from simple rules.

How It Works

Agent Behavior

Each "slime" agent follows a simple set of rules:

  1. Sense - Check pheromone levels at three sensors (forward, left, right)
  2. Steer - Turn toward the direction with highest pheromone concentration
  3. Move - Take a step forward in the current direction
  4. Deposit - Leave a trail of pheromone at the current position

Pheromone Dynamics

The pheromone field undergoes two processes each frame:

  • Diffusion - Pheromones spread to neighboring cells using a blur operation
  • Evaporation - Pheromone levels gradually decay over time

Steering Algorithm

// Sense in three directions
float weightForward = sense(agent, 0);
float weightLeft = sense(agent, sensorAngle);
float weightRight = sense(agent, -sensorAngle);

// Turn toward highest concentration
if (weightForward > weightLeft && weightForward > weightRight) {
    // Continue straight
} else if (weightLeft > weightRight) {
    agent.angle -= turnSpeed * dt;
} else {
    agent.angle += turnSpeed * dt;
}

Parameters

The simulation behavior can be dramatically altered by adjusting these parameters:

  • Sensor Angle - How far apart the left/right sensors are
  • Sensor Distance - How far ahead the sensors look
  • Turn Speed - How quickly agents can change direction
  • Diffuse Speed - How fast pheromones spread
  • Evaporation Rate - How quickly trails fade

The simulation dynamically varies these parameters over time, creating an ever-evolving visual display.

Multiple Species

Version 3.0 of the simulation introduces multiple "species" of agents, each with their own color (red, green, or blue). Agents are attracted to trails of their own species but repelled by trails of other species.

This creates fascinating territorial patterns as the different populations compete for space and form complex boundaries.

Technical Details

Built with Processing (Java-based creative coding environment), the simulation features:

  • 2000+ simultaneous agents
  • Pixel-level rendering for performance
  • Real-time parameter animation
  • Multi-species interaction
