Polygon

Generative Polygon Art

Polygon is a generative art piece that creates geometric patterns using connected vertices. Each refresh produces a unique composition of interconnected shapes that slowly evolve over time.

The Concept

The idea behind Polygon is simple: scatter a set of particles across the canvas subject to simple rules, then connect nearby particles with lines. As the particles move, the connections update, creating an ever-shifting web of geometric forms. The result is a display where rigid polygons emerge organically from the chaos of moving points. It's a visualization of how order can arise from simple rules applied to random initial conditions.

How It Works

The algorithm consists of a few key components:

Particle System

A collection of particles is initialized at random positions. Each particle has a velocity that causes it to drift across the canvas.

Connection Logic

For each frame, the algorithm calculates the distance between every pair of particles. If two particles are within a threshold distance, a line is drawn between them.

Visual Style

The opacity of each connection line is based on distance—closer particles create stronger (more opaque) lines, while distant particles have faint connections. This creates a natural depth effect.

Technical Details

Built with p5.js, the sketch uses:

  • Object-oriented particle management
  • Distance-based line rendering
  • Boundary wrapping for seamless animation
  • Real-time performance optimization
